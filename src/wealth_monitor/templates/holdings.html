HOW IT WORKS

使用方法

  1. 第一次买入时录入产品代码、日期和份额。
  2. 追加买入或部分赎回时，再记录一笔变动。
  3. GitHub Actions 更新公开净值后，重新打开或刷新本页即可自动重算。

不在当前数据池中的产品也可以先保存。云端匹配到该产品的公开净值后，本页会自动开始计算。
